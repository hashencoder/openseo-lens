Speed test (optional)

The Lighthouse test works without a key, but then it shares one daily quota with everyone else using Google PageSpeed without a key, and that quota can run out. When it does, the Speed tab offers a free, no-sign-in alternative on pagespeed.web.dev.

If you test often, you can add your own free PageSpeed Insights API key to get a private daily quota. Creating one needs a Google account: get a key ↗. The key is stored only on this computer and sent only to googleapis.com.

Data & privacy

On-page analysis never leaves your machine. Only these optional public endpoints are contacted, and only when you open the related tab:

  • tranco-list.eu — popularity rank
  • rdap.org — domain registration dates
  • web.archive.org — Wayback Machine history
  • cloudflare-dns.com — DNS records
  • googleapis.com/pagespeedonline — Lighthouse test (only when you click Run)
  • wikipedia.org, hn.algolia.com, lobste.rs, api.stackexchange.com — backlink sources (Backlinks tab)
  • suggestqueries.google.com — keyword ideas (only when you click Get ideas)
